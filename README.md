# Portfolio website

Prebuilt static portfolio. The site entry point is `index.html`; all media is in `assets/` and uses relative URLs. No build command or application server is required.

## GitHub Pages

Publish the `main` branch from `/(root)` in Settings → Pages. `.nojekyll` keeps the prebuilt files unchanged.

## Preview

Run `python -m http.server 8000` from this directory, then open http://localhost:8000/.
